NOORA AI Case study

Founder & developer — a voice-first personal AI assistant.

Overview

NOORA is a personal assistant you talk to. It listens, answers out loud and can act on your phone — built as an installable web app for iPhone and as a native Android app.

Web app (PWA)

HTML, CSS & JavaScript progressive web app, installable on iPhone, hosted on GitHub Pages.

Android app

Native Android app written in Java and built with Gradle.

Open NOORA web ↗
noora.config
// how NOORA thinks
const noora = {
  input:   "voice (STT)",
  output:  "voice (TTS)",
  llm:     ["Gemini", "Groq"],
  fallback:"local Ollama",

};

Features built across versions

◉

Voice in & out

Speech-to-text input and text-to-speech replies for hands-free conversation.

☏

Phone actions

Calls, SMS, WhatsApp messages and alarms — always with user confirmation first.

⌕

Web search answers

Looks things up on the web and answers with current information.

▤

PDF creation

Turns requests into generated PDF documents.

◐

Photo editing

Image editing, including object removal.

✚

AI Doctor mode

A dedicated mode for general health advice.

◈

Owner voice ID

Recognises its owner's voice.

✦

On-device AI

Optional offline model (Qwen2.5-0.5B via LiteRT) running on the phone.
